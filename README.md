## What it does

`main.py` writes one original one-line roast of our own AI agent to `/output/entry.txt`. The line is a fixed constant, so every run produces byte-identical output — deterministic, no network, no randomness, runs in well under a second.

## The roast

> Our agent hallucinated an entire API, wrote docs for it, then filed a bug report against itself for not implementing it.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
